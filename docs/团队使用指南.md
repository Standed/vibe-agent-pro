# Video Agent Pro - 团队使用指南

> **适用对象**：西羊石团队内部成员  
> **最后更新**：2026 年 3 月  
> **平台版本**：v4.0.6

---

## 📌 这个平台是做什么的？

Video Agent Pro 是我们团队自研的 **AI 视频分镜生产工具**。你可以用它：

- **输入一个剧本** → AI 自动拆解为场景和分镜
- **生成分镜图片** → 使用 Gemini / 即梦等模型一键出图
- **生成视频** → 使用 Sora / Vidu / SeeDance 等模型将分镜图转为视频
- **管理整个项目** → 无限画布 + 时间轴 + 角色管理 + 聊天历史

**核心提效数据**：一集 2 分钟的漫剧，约 5 分钟可出初版视频，1 小时内完成可用素材。

## 🚀 快速上手（5 分钟入门）

### 第一步：登录

1. 打开平台地址（xysaiai.com）
2. 使用分配的账号密码登录
3. 首次登录需要找小石开通白名单，等待审批即可

> 💡 如果登录后显示"待审批"状态，找管理员开通 `is_whitelisted` 权限。

### 第二步：创建项目

1. 点击首页 **「创建新项目」**
2. 输入项目名称（如"产品宣传片"）
3. 选择画面比例（推荐 16:9 横屏或 9:16 竖屏）
4. 进入项目编辑页面

### 第三步：理解三大视图

进入项目后，顶部有三个视图切换按钮：

```
📝 故事构思 (Planning)  →  🖼️ 图片生成 (Canvas)  →  🎬 视频输出 (Timeline)
```

| 视图 | 你在这里做什么 | 何时使用 |
|------|----------------|----------|
| **故事构思** | 输入剧本，AI 拆分场景和分镜 | 项目开始时 |
| **图片生成** | 在画布上查看分镜，生成分镜图片 | 拆完分镜后 |
| **视频输出** | 预览和生成视频，管理任务队列 | 图片就绪后 |

## 📝 故事构思（Planning）

### 操作流程

1. 切换到 **「故事构思」** 视图
2. 在左侧输入或粘贴你的剧本文本
3. 点击 **「AI 生成分镜」**
4. AI 会自动：
   - 将剧本拆分为多个场景（Scene）
   - 每个场景拆分为多个分镜（Shot）
   - 提取角色和地点信息
5. 检查拆分结果，可以手动调整

> 💡 **技巧**：剧本越详细，拆分结果越准确。建议包含镜头描述、角色动作、情绪等信息，总分镜数量。

## 🖼️ 图片生成（Canvas）

这是你花时间最多的视图。这里有两种工作模式：

### Agent 模式（推荐新手使用）

右侧面板切换到 **「Agent」** 标签，用自然语言对 AI 说：

```
常用指令：
"生成分镜 1 的图片"
"批量生成场景 2 的所有分镜图片"
"生成一个 3×3 的 Grid"
"批量生成整个项目的图片"
"生成角色三视图"
```

Agent 会自动选择合适的模型和参数，你只需确认即可。

> ⚠️ **重要**：涉及积分消耗的操作，Agent 会先弹出确认弹窗，显示预计消耗积分，你确认后才执行。不用担心误操作。

### Pro 模式（进阶使用）

右侧面板切换到 **「Pro」** 标签，手动控制生成参数：

1. 在画布上**点击选中**一个分镜
2. 选择生成模式：
   - **Grid 多视图**：一次生成 2×2 或 3×3 多张图片
   - **Gemini 单图**：生成单张高质量图片
   - **即梦**：中文优化的图片生成
3. 设置参数（风格、比例等）
4. 可上传**参考图**，AI 会参照风格生成
5. 输入提示词，点击生成

### Grid 图片的使用

Grid 是我们最常用的生成方式——一次生成多张图片，选最好的用：

1. 生成 Grid 后，会显示完整的网格图
2. 点击查看每张切片
3. **拖拽切片到画布上的分镜**，即可将图片应用到对应分镜
4. 也可以点击 **「一键应用」** 自动分配

> 💡 **技巧**：Grid 3×3 出 9 张图，总会有几张满意的。比单张生成效率更高。

### 参考图管理

- **拖拽上传**：直接把图片拖到 Pro 面板的参考图区域
- **@提及**：在输入框输入 `@角色名` 会自动加载该角色的参考图
- **跨分镜隔离**：切换分镜时参考图会自动重置，不会互相干扰

## 🎬 视频生成（Timeline）

### 前提条件

分镜必须先有图片（通过上面的步骤生成），才能生成视频。

### 使用 Agent 模式（推荐）

```
常用指令：
"用 Sora 生成分镜 1 的视频"
"生成分镜 14-16 的视频"
"批量生成所有分镜的视频"
"用 Vidu 生成分镜 5 的视频"
```

### 使用 Pro 模式

1. 选中一个有图片的分镜
2. 切换到 **「Pro」** 模式
3. 选择视频提供商：

| 提供商 | 特点 | 推荐场景 |
|--------|------|----------|
| **Sora 2 Pro** | 画质最好，支持 15s/25s | 正式产出 |
| **Vidu** | 速度快，支持首尾帧 | 快速预览、过渡镜头 |
| **SeeDance** | 新一代模型，质量高 | 正式产出（推荐） |

4. 配置参数（时长、分辨率等）
5. 点击生成，等待任务完成

### 视频任务管理

- 视频生成是异步的，提交后可以继续做其他事
- 左侧面板会显示所有任务的状态：排队中 → 生成中 → 完成 / 失败
- 完成的视频会自动保存到云端（R2 存储），不会丢失
- 可以在 Timeline 视图预览所有已生成的视频

## 🎭 角色和地点管理

### 创建角色

1. 在左侧边栏点击 **「角色」** 标签
2. 点击 **「+ 添加」**
3. 填写角色信息：名称、外貌描述、风格
4. 可选：点击 **「AI 生成三视图」**（正面/侧面/背面参考图）

### 创建地点

1. 在左侧边栏点击 **「地点」** 标签
2. 点击 **「+ 添加」**
3. 填写地点信息

> 💡 角色和地点信息会被 Agent 自动引用，帮助保持画面一致性。

## 🎯 高效工作流（推荐流程）

### 标准产出流程

```
1. 准备剧本（5分钟）
   └── 写好剧本，包含场景描述和镜头指示

2. AI 拆分分镜（2分钟）
   └── 故事构思视图 → AI 生成分镜 → 检查调整

3. 批量生成分镜图片（10-15分钟）
   └── Canvas 视图 → Agent: "批量生成所有分镜图片"
   └── 检查结果，不满意的单独重新生成

4. 批量生成视频（等待时间，可做其他事）
   └── Timeline 视图 → Agent: "批量生成所有视频"
   └── 提交后等待，系统自动轮询和保存

5. 预览和调整（10-20分钟）
   └── Timeline 预览视频，不满意的重新生成
```

### 效率技巧

1. **善用 Agent 批量操作**：一句话批量生成，比逐个操作快 5 倍
2. **Grid 优于单图**：3×3 Grid 出 9 张图，挑选最好的，比连续生成单图效率高
3. **参考图保持一致**：上传一张满意的参考图，后续生成都参考它
4. **不满意就重新生成**：AI 生成有随机性，多试几次总能出好的
5. **视频提交后去做别的**：不需要盯着等，完成后系统会自动保存
6. **用 @提及自动加载参考**：输入 `@角色名` 自动关联角色参考图，省去手动上传

## ⚠️ 常见问题

### 图片生成失败怎么办？

- 检查网络是否正常（需要能访问 Google API）
- 确认积分是否充足
- 换一个提示词重试

### 视频一直显示"生成中"？

- 视频生成通常需要 2-5 分钟
- 如果超过 10 分钟仍未完成，可能是任务失败了，重新提交即可
- 系统有 Cron 定时任务会自动检查和重试

### 刷新页面后图片丢了？

- 正常情况下刷新不会丢失（所有图片都自动保存到云端）
- 如果确实丢失，告知管理员使用资产修复工具

### 页面加载很慢？

- 大项目（50+ 分镜）首次加载可能较慢，属正常现象
- 建议单个项目控制在 30 个分镜以内
- 超大项目可以拆分为多个项目

### 怎么下载生成的图片/视频？

- 图片：在画布上右击分镜图片，选择"下载"
- 视频：在 Timeline 视图点击视频的下载按钮
- Grid 图片：在 Grid 预览中点击单张图片的下载按钮
